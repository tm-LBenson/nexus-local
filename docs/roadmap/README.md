# Roadmap Details

This directory expands the broad roadmap into phase-level plans. Each phase has:

- customer outcome
- product scope
- implementation slices
- dependencies
- release gates
- first build candidates

Use these files as the planning layer between product vision and code work.

## Phases

1. [MVP Stabilization](phase-01-mvp-stabilization.md)
2. [Data Sources and Ingestion](phase-02-data-sources-ingestion.md)
3. [Retrieval and Answer Quality](phase-03-retrieval-answer-quality.md)
4. [Security, Identity, and Governance](phase-04-security-governance.md)
5. [Operator Deployment Experience](phase-05-operator-deployment.md)
6. [Workflow and Agent Foundation](phase-06-workflows-agents.md)
7. [Production Scale and Packaging](phase-07-production-scale.md)

## Implementation Rule

Do not start a phase because it sounds exciting. Start it when its dependencies are strong enough that the result will be useful, testable, and safe.
